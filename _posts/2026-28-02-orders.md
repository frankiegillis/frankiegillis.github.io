## The Countable, Dense Linear Order Without Endpoints

A set $X$ is called *strictly linearly ordered* if there is an order $<$ on $X$ such that:

* For all $a$, $b$, $c \in X$, if $a < b$ and $b < c$, then $a < c$ (transitivity)
* For all $a$, $b \in X$, exactly one of $a = b$, $a < b$, $b < a$ is true (trichotomy)

Say that $X$ is *dense* if for all $a$, $b \in X$ with $a < b$, there exists $c \in X$ such that $a < c < b$. Think $([0,1] , <) $.

Say that $X$ *has no endpoints* if for all $a \in X$, there exist $b$, $c \in X$ such that $b < a < c$. Think $(\mathbb{Z}, <)$.

An example of a dense linear order with no endpoints is $(\mathbb{R}, <)$. An example of a countble, dense linear with no endpoints is $(\mathbb{Q}, <)$.
