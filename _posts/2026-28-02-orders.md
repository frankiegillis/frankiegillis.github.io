## The Countable, Dense Linear Order Without Endpoints

A set $X$ is called *strictly linearly ordered* if there is an order $<$ on $X$ such that:

* For all $a$, $b$, $c \in X$, if $a < b$ and $b < c$, then $a < c$ (transitivity)
* For all $a$, $b \in X$, exactly one of $a = b$, $a < b$, $b < a$ is true (trichotomy)

Say that $X$ is *dense* if for all $a$, $b \in X$ with $a < b$, there exists $c \in X$ such that $a < c < b$. Think $([0,1] , <) $.

Say that $X$ *has no endpoints* if for all $a \in X$, there exist $b$, $c \in X$ such that $b < a < c$. Think $(\mathbb{Z}, <)$.

An example of a dense linear order with no endpoints is $(\mathbb{R}, <)$, but notice that this order is not countable. The countable, dense linear with no endpoints is $(\mathbb{Q}, <)$. Why the definite article? A remarkable fact
about countable, dense linear orders without endpoints (that we proved as a tutorial problem in MT5861 Advanced Combinatorics at St Andrews) is that there is precisely one up to isomorphism.

**Definition.** If $(X, <)$ and $(Y, <)$ are linear orders, then a bijection $f \colon X \to Y$ is called an *order isomorphism* if for every $a$, $b \in X$ with $a < b$, we have $f(a) < f(b)$. Notice that, by trichotomy, there are no non-relations to be preserved, so being an order isomorphism is the same as being a bijective order homomorphism. We write $X \cong Y$ to denote order isomorphism.

**Theorem.** Let $X$ and $Y$ be countable, dense linear orders without endpoints. Then $X \cong Y$.

The proof of this is the original example of a so-called back-and-forth argument, used frequently in infinite combinatorics (another example being the random graph). This argument is due to Cantor.

*Proof.* Since $X$ and $Y$ are countable, we can enumerate them as $X = \set{a_0, a_1, a_2 \dots}$ and $Y = \set{b_0, b_1, b_2, \dots}$ (this enumeration definitely does not respect the orders). The idea is to inductively define an order isomorphism $f \colon X \to Y$ by adding an element of $X$ to the domain of $f$ at every even step, and adding an element of $Y$ to the image of $f$ at every odd step. This is the 'back-and-forth,' and is the reason we will be able to
declare that the domain of $f$ is the whole of $X$, and the range of $f$ is the whole of $Y$. We will 'feed' our enumerations of $X$ and $Y$ into $f$, one element at a time. 

**Base case:** Define $f_0 \colon \set{a_0} \to \set{b_0}$ by $f_0(a_0) = b_0$. This is an order isomorphism from $\set{a_0}$ to $\set{b_0}$ since there are no relations to check.

**Inductive step:** Assume that the isomorphism $f_k \colon A_k \to B_k$ has been constructed, where $A_k \subseteq X$, $B_k \subseteq Y$ are finite sets. The next step depends on whether $k$ is even or odd.

* Assume that $k$ is even. We will add the next element in our enumeration of $X$ which hasn't yet been added to the domain of $f_k$.  Let $a_i \in G$, where $i$ is the smallest natural number such that $a_i \notin A_k$. By trichotomy, there
  exists $C \subseteq A_k$ such that $c < a_i$ for all $c \in C$, and $a_i < d$ for all $d \in A_k \setminus C$. ($C$ or $A_k \setminus C$ may be empty, but this is accounted for). Then, $B_k = \varphi_k (C) \cup \varphi_k{A_k \setminus C}$ since $\varphi_k$ is a bijection.
We want to find $b \in H$ such that $c < b < d$ for all $c \in \varphi_k(C)$ and $d \in \varphi_k(A_k \setminus C)$. This has three subcases.
    * Suppose that $C = \emptyset$. Then $\varphi_k(C) = \emptyset$, and $ \varphi(A_k \setminus C) = \varphi_k( A_k ) = B_k$. Since $B_k$ is a finite
                                        linear order, it has some minimal element $n \in B_k$ such that $n < d$ or $n = d$ for all $d \in B_k$. Since $H$ has no endpoints, there
                                        exists $b \in H$ such that $b < n$. By transitivity, $b < d$ for all $d \in B_k$. This gives the desired $b$.
    * Suppose that $C = A_k$. Then $\varphi_k(C) = B_k$, and $ \varphi(A_k \setminus C) = \emptyset$. Since $B_k$ is a finite

    * Suppose that $C \ne \emptyset$ and $C \ne A_k$. Since $\varphi_k(C)$ is a finite linear order, it has a maximal element
                                        $m \in \varphi_k(C)$ such that $c < m$ or $c = m$ for all $c \in \varphi_k(C)$. Similarly, since $\varphi_k(A_k \setminus C)$ is a
                                        finite linear order, it has a minimal element $n \in \varphi_k(A_k \setminus C)$ such that $n < d$ or $n = d$ for all
                                        $d \in \varphi_k(A_k \setminus C)$. Since $H$ is dense, there exists an element $b \in H$ such that $m < b < n$.
                                        Then, by transitivity, we have $c < b < d$ for all $c \in \varphi_k(C)$ and $d \in \varphi_{k}(A_k \setminus C)$, as desired
      Define $\varphi_{k + 1} \colon A_k \cup \{a_i\} \to B_k \cup \{b\}$ by $\varphi_{k+1}(a_i) = b$, and $\varphi_{k+1}(a) = \varphi_k(a)$ for all $a \in A_k$.
      By the choice of $b$ and the fact that $\varphi_k$ is an order isomorphism, $\varphi_{k+1}$ is an order isomorphism.
* Assume that $k$ is odd. Let $b_i \in H$, where $i$ is the smallest natural number such that $b_i \notin B_k$. Since $\varphi_k$ is a bijection, it has
  an inverse $\varphi^{-1}_k \colon B_k \to A_k$. By trichotomy, there exists $C \subseteq B_k$ such that $c < b_i < d$ for all $c \in C$ and $d \in B_k \setminus
  C$. Since $\varphi^{-1}_k$ is a bijection, we have that $A_k = \varphi^{-1}_k(C) \cup \varphi^{-1}_k(B_k \setminus C)$.
  Using the same argument as in the $k$ even
  case but in $G$, we may find $a \in G$ such that $c < a < d$ for all $c \in \varphi^{-1}_k(C)$ and $d \in \varphi^{-1}_k(B_k \setminus C)$. We then define
  the bijection $\varphi_{k+1} \colon A_k \cup \{a\} \to B_k \cup \{b_i\}$ by $\varphi_{k+1}(a) = b_i$, and $\varphi_{k+1}(x) = \varphi_k(x)$ for all $x \in A_k$.
  By the choice of $a$, and the fact that $\varphi_k$ is an order isomorphism, it follows that $\varphi_{k+1}$ is an order isomorphism.

Now define $\varphi = \bigcup_{i \in \NN_0} \varphi_i$. Since each $a_i \in G$ is accounted for at some even step in the induction, it follows that the domain of $\varphi$ is
        $G$. Since every $b_i \in H$ is accounted for at every odd step of the induction, it follows that the image of $\varphi$ is $H$. Since each $\varphi_i$ is an order isomorphism,
        it follows that $\varphi$ is an order isomorphism. Therefore, $G$ and $H$ are isomorphic as linear orders. \par
        Up to isomorphism, this unique linear order is $(\QQ, <)$.
